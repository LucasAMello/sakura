 -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=- I. Introduction -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

   Before I start, thank you for playing my game and reading the readme.txt before(I hope)
 playing it. This game was made by a beginner programmer, therefore its quality is questionable,
 but I hope you enjoy playing it as much as I enjoyed making it. The game is a classical
 side-scroller, where you must go through different stages, battling various enemies. There is
 no history, so just go and shoot anything that moves!

   This software is provided 'as is' with no warranty of any kind. I cannot be held in any way
 responsible for any damage caused by this program. Use this software at your own risk.

   This game was made using C++, the Allegro library (http://alleg.sourceforge.net) and
 compiled in Dev-C++ (www.bloodshed.net).

 
 -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=- II. Controls -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

 F - Jump;
 D - Shoot;
 S - Change Card(right);
 A - Change Card(left);
 Enter - Game Menu;
 1 to 7 - Change Card;
 O - Show FPS;
 P - Stop BGM;
 ESC - Quit Game (don't forget to save!);


 -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-  III. Tips  -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

 * If the game is too slow, check the FPS. If it's below 40, try closing other applicatives
 or restart your computer. If this doesn't help, run Sakura(graphics select).exe and change
 the color depth to 16, resolution 640x480 and try it windowed or full screen.
 * Don't forget to save frequently!
 * Each boss has a weakness to a certain card, which makes beating it a lot easier.
 * Get as many cards as you can! Something good might happen ;)
 * Don't give up! The game is easy, try to memorize the attack paterns and you'll do well.


 -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-  IV. Cheats  -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

    After beating the game, if you meet certain requirements a screen teaching you a code
 will appear. Type this code to enter cheat mode, and then press any of these keys to get
 the desired effect:

 + = Change BGM(+);
 - = Change BGM(-);
 G = God mode;
 L = Heal all your hit points;
 K = Kill yourself (lol);
 V = 9 lives;
 M = Get all cards;
 J = Go to the last boss;
 B = Turn cheat mode off;


 -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=- V. Problems and errors -=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

 ! Any error or bug should be reported to kerowasukidesu@yahoo.com.br !

   - If you are running under Vista and the game crashes in the begining of a stage, right-click
 Sakura.exe, Properties, Compatibility, Execute in..., Windows 98 / ME, and it should work...
   - After killing a boss, KEEP YOUR HANDS OFF THE KEYBOARD OR YOUR PC WILL EXPLODE!!!

 * For your computer's and your own good, don't modify any of the files present;
 * If the game freezes, change screens with Alt + Tab and close it with Ctrl + Alt + Del;
